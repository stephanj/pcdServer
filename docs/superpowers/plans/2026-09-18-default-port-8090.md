# Default Port 8090 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make port 8090 the runtime, library, help-text, and documented default for PCD Server.

**Architecture:** Keep the existing command-line parsing and HTTP server API intact while changing their two public default declarations in sync. Add a CTest command-level regression around the built executable, then update the README so every current invocation and URL matches the executable.

**Tech Stack:** C++20, CMake/CTest, Markdown

### Task 1: Lock the CLI default in a regression test

**Files:**
- Modify: `CMakeLists.txt`
- Test: built `pcd_server` executable through CTest

- [ ] **Step 1: Register a failing help-output test**

Add after `catch_discover_tests(pcd_tests)`:

```cmake

    PASS_REGULAR_EXPRESSION "--port PORT           default 8090"

```

Expected: FAIL because help prints `default 8080`, not `default 8090`.

- [ ] **Step 3: Commit the red test**

```bash

```
