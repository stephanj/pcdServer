  How one decode works
  
      
    
    1. Schema prefix. The system prompt listing every field, description and allowed value is rendered through the model's chat template. The first time, it is prefilled and a full sequence checkpoint is saved; afterwards that checkpoint is restored (hit).
      2. 
    
    2. Dynamic context. Your input, the end of the user turn and the start of the assistant answer are decoded on top.
      3. 
    
    3. Broadcast. The completed prefix is copied to one sequence per field.
      4. 
    
    4. Suffix. Each sequence gets its own "field":  opener in a single batch; logits are read only at each opener's last token.
      5. 
    
    5. Score. Softmax over the allowed next tokens only. Choices that share the winning token are separated level by level, one batched pass per level.
      6. 
    
    6. Assemble. The JSON is built from the winners, so it can never miss a key or contain a value outside the schema.

    Every falling piece is one decode call: the board is the input, the legal placements are the
      allowed values of a single field, and the decoder picks one in two forward passes. At temperature 0 it takes the
      most probable placement; higher values sample from the distribution. Candidates are labelled with their outcome
      first (“clears 2 lines - column 4, rotation 0”). By default the game engine offers only the best outcome class —
      every placement that completes the most lines, or, failing that, those creating the fewest holes — and the model
      chooses among them; offer all legal placements to see how a small model does on its own.

        What the model is asked
        
      The prompt is the board as a 10×20 grid of #/., the column heights, the falling
          and next piece, plus one candidate per legal placement whose label leads with its outcome (lines cleared, or new
          holes and resulting height) followed by the column and rotation. The schema has one field,
          placement, whose allowed values are exactly those labels — so an illegal move is impossible, and
          the decoder's first scored token separates “clears …” from “no line …”. A small model is a weak spatial reasoner: the interesting part is
          watching it decide many times per second with a calibrated probability per option, not whether it beats the
          simple heuristic shown for reference.
